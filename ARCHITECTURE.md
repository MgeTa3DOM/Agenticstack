# Sovereign AI Infrastructure Architecture

This document outlines the architecture for the Agentic Co-Work Engineering Dashboard, designed for the "1st Billionaire Single Dev Manager".

The goal is to integrate AI workflow, 3D avatar auto-streaming, and robust secure sandboxing natively.

## Core Components

### 1. Agentic Dashboard (Node.js/Express Web Interface)
*   **Purpose:** The central management plane. A unified interface to interact with AI models, monitor live avatar streams, and provision/manage secure isolated compute environments.
*   **Tech Stack:** Node.js, Express, HTML/CSS/JS (Vanilla).

### 2. AI Workflow (Claude & Gemini API Integration)
*   **Purpose:** The reasoning engine. AI acts as the co-pilot, capable of writing code, analyzing logs from the sandboxes, and orchestrating the avatar responses.
*   **Integration:** Natively through official API SDKs. The dashboard will maintain context and state across sessions, proxying requests to either Anthropic (Claude) or Google (Gemini) based on task suitability (e.g., Claude for complex coding, Gemini for rapid multimodal analysis).

### 3. 3D Avatar Auto-Stream (FFmpeg Native)
*   **Purpose:** A human-like representation of the AI assistant for live "dev stream" co-working sessions.
*   **Integration:**
    *   Audio generated by TTS (Text-to-Speech) engines based on AI responses.
    *   **FFmpeg** handles the real-time muxing of audio and pre-rendered 3D avatar animations (or dynamically generated video frames) into a streamable format (HLS/WebRTC).
    *   The dashboard will embed a native video player consuming the FFmpeg output stream.

### 4. SandboxEvision (Firecracker MicroVMs)
*   **Purpose:** Extremely fast, secure, and isolated execution environments for running code generated by the AI or executing untrusted tasks.
*   **Integration:**
    *   Native integration via the Firecracker API (interacting over a Unix domain socket).
    *   The Node.js server acts as the orchestrator, sending requests to the Firecracker daemon to boot lightweight Linux kernels and rootfs images in milliseconds.
    *   This provides AWS Lambda-like security and execution speed natively on the dev machine/server.

## Workflow Execution

1.  **User Request:** The user inputs a command in the dashboard (e.g., "Analyze this dataset and create a python script").
2.  **AI Routing:** The request is sent to Claude/Gemini.
3.  **Avatar Reaction:** The AI's response is converted to speech, triggering FFmpeg to stream an animated 3D avatar "speaking" the response back to the dashboard.
4.  **Actionable Output:** If the AI generates code, the dashboard orchestrator spins up a Firecracker MicroVM.
5.  **Execution & Feedback:** The code runs in the secure microVM. Execution logs and results are streamed back to the dashboard and fed back into the AI context window.
