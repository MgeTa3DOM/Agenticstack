## The 7 Principles

### 1. Your Hardware, Your Intelligence
AI must run on hardware you own or control. Cloud should be a choice, never a requirement. The default must be local.

### 2. Your Data Never Leaves
Zero telemetry. Zero data collection. Zero cloud callbacks. Every byte stays on your machine unless you explicitly choose otherwise.

### 3. Transparency Over Black Boxes
Every workflow is a visible DAG. Every decision has a trace. No hidden prompts. No secret system messages. No opaque "AI magic."

### 4. Encryption by Default
ChaCha20-Poly1305. X25519. Ed25519. Double Ratchet. Military-grade cryptography is not a premium feature — it is the baseline.

### 5. Contribution Over Extraction
No venture capital. No debt. No rent-seeking. The system finances itself through community contributions. Value flows to creators, not extractors.

### 6. Autonomy Over Dependency
3,000 agents that work for you, not for a corporation. They don't phone home. They don't require API keys from third parties. They are yours.

### 7. Open Source Forever
MIT licensed. Fork it. Modify it. Redistribute it. Build on it. The code belongs to everyone. The revolution cannot be proprietary.
